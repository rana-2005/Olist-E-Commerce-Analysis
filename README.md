# Olist E-Commerce Analysis

An end-to-end analysis of Brazilian e-commerce data to understand sales performance, customers, products, delivery, sellers, payments, and geographic performance.

## Tools
- Power BI & Power Query (data cleaning, modeling, dashboard)
- SQL (data analysis)

## Dataset
Brazilian E-Commerce Public Dataset by Olist (Kaggle).

## Dashboard Pages
1. **Sales & Payments**: revenue, orders, average order value, payment types
2. **Products, Sellers & Customers**: top categories, top sellers, customer reviews
3. **Delivery, Satisfaction & Geography**: delivery time, late deliveries, orders by state
